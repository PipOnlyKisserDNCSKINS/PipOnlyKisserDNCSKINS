𝑨𝒏𝒅 𝒚𝒆𝒔, 𝑰 𝒌𝒏𝒐𝒘 𝑰’𝒎 20,  𝒃𝒖𝒕 𝑴𝒀 𝒀𝑼𝑴𝑬𝑺𝑶𝑵𝑨 𝑰𝑺 𝑵𝑶𝑻 𝑴𝑬;  𝒉𝒆 𝒊𝒔 𝒂 𝒄𝒐𝒎𝒑𝒍𝒆𝒕𝒆𝒍𝒚 𝒅𝒊𝒇𝒇𝒆𝒓𝒆𝒏𝒕 𝒑𝒆𝒓𝒔𝒐𝒏,  𝒂𝒏𝒅 𝒉𝒆’𝒔 𝒕𝒉𝒆 𝒔𝒂𝒎𝒆 𝒂𝒈𝒆 𝒂𝒔 𝑷𝒊𝒑.  𝑾𝑬 𝑨𝑹𝑬 𝑵𝑶𝑻 𝑻𝑯𝑬 𝑺𝑨𝑴𝑬—𝒑𝒍𝒆𝒂𝒔𝒆  𝒅𝒐𝒏’𝒕 𝒄𝒐𝒎𝒑𝒂𝒓𝒆 𝒖𝒔.  𝑴𝒀 𝑶𝑪 𝑰𝑺 𝑴𝑨𝑳𝑬, 𝑨𝑵𝑫 𝑰 𝑨𝑴 𝑭𝑬𝑴𝑨𝑳𝑬.  𝑰 𝒅𝒐𝒏’𝒕 𝒉𝒂𝒗𝒆 𝒂𝒏𝒚 𝒊𝒍𝒍 𝒊𝒏𝒕𝒆𝒏𝒕𝒊𝒐𝒏𝒔  𝒓𝒆𝒈𝒂𝒓𝒅𝒊𝒏𝒈 𝒆𝒊𝒕𝒉𝒆𝒓 𝒗𝒆𝒓𝒔𝒊𝒐𝒏 𝒐𝒇 𝒕𝒉𝒆  𝒄𝒉𝒂𝒓𝒂𝒄𝒕𝒆𝒓; 𝑰’𝒎 𝒏𝒐𝒕 𝒊𝒏𝒕𝒐 𝒕𝒉𝒂𝒕 𝒌𝒊𝒏𝒅  𝒐𝒇 𝒔𝒕𝒖𝒇𝒇—𝒊𝒕  𝒂𝒄𝒕𝒖𝒂𝒍𝒍𝒚 𝒈𝒓𝒐𝒔𝒔𝒆𝒔 𝒎𝒆 𝒐𝒖𝒕.  𝑷𝒊𝒑 𝒉𝒂𝒔 𝒃𝒆𝒆𝒏 𝒂𝒏 𝒊𝒎𝒑𝒐𝒓𝒕𝒂𝒏𝒕 𝒑𝒂𝒓𝒕  𝒐𝒇 𝒎𝒚 𝒍𝒊𝒇𝒆 𝒆𝒗𝒆𝒓 𝒔𝒊𝒏𝒄𝒆 𝑰 𝒅𝒊𝒔𝒄𝒐𝒗𝒆𝒓𝒆𝒅  𝒕𝒉𝒆 𝒄𝒉𝒂𝒓𝒂𝒄𝒕𝒆𝒓; 𝒉𝒆’𝒔 𝒉𝒆𝒍𝒑𝒆𝒅 𝒎𝒆 𝒕𝒉𝒓𝒐𝒖𝒈𝒉  𝒔𝒐𝒎𝒆 𝒉𝒐𝒓𝒓𝒊𝒃𝒍𝒆 𝒑𝒆𝒓𝒔𝒐𝒏𝒂𝒍 𝒆𝒙𝒑𝒆𝒓𝒊𝒆𝒏𝒄𝒆𝒔  𝒇𝒓𝒐𝒎 𝒎𝒚 𝒑𝒂𝒔𝒕, 𝒍𝒊𝒌𝒆 𝒅𝒆𝒑𝒓𝒆𝒔𝒔𝒊𝒐𝒏, 𝒆𝒕𝒄. 𝑺𝒐,  𝒃𝒆𝒇𝒐𝒓𝒆 𝒚𝒐𝒖 𝒔𝒕𝒂𝒓𝒕 𝒕𝒓𝒂𝒔𝒉𝒊𝒏𝒈 𝒎𝒆,  𝑷𝒊𝒑 𝒎𝒆𝒂𝒏𝒔 𝒆𝒗𝒆𝒓𝒚𝒕𝒉𝒊𝒏𝒈 𝒕𝒐 𝒎𝒆.  𝑾𝒊𝒕𝒉 𝒕𝒉𝒆 𝑺𝑷 𝒗𝒆𝒓𝒔𝒊𝒐𝒏, 𝒊𝒕’𝒔 𝒋𝒖𝒔𝒕 𝒂 𝒔𝒘𝒆𝒆𝒕,  𝒊𝒏𝒏𝒐𝒄𝒆𝒏𝒕, 𝒔𝒄𝒉𝒐𝒐𝒍-𝒔𝒕𝒚𝒍𝒆 𝒄𝒓𝒖𝒔𝒉—𝒏𝒐𝒕𝒉𝒊𝒏𝒈  𝒘𝒆𝒊𝒓𝒅.
